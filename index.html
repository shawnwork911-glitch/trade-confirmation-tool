Move Old Files to New Folders

One-off tool. Moves files saved in the old layout (Period/Department/Company, or folders named after the AP number like AP-20260925-uwxj) into Entity/Period/Department/Company, where Period is the semi-monthly folder of the request's approval date (requests not yet approved are left where they are and move automatically when approved). The entity (MY / SG) comes from the request's currency and the company folder from its vendor name; saved links are updated. Run Scan first — nothing moves until you click Move. Old empty folders are left in place.

    

    

      

        

          
Backfill Operations Approvals → Checked

          
One-off tool. New Operations approvals already set Verification to Checked and add "All documents checked by approver …" to the verification notes. This applies the same to Operations requests approved before that change (status Approved – Pending Finance, Pending – More Info Needed or Processed). Existing verification notes are kept; the line is added underneath using the original approver and approval date. Requests that already have the line are skipped, so it is safe to run again. Run Scan first — nothing changes until you click Apply.
